# FPC-NitroFlow

Автоматическая продажа подарочных ссылок Discord Nitro на FunPay через Lolz Market. Работает самостоятельно, без Cardinal.

Бот проверяет оплаченный заказ, подбирает товар у разрешённого поставщика, закупает и выдаёт ссылку в чат. Поддерживает команды, историю покупателей, защиту от повторной выдачи и напоминание о подтверждении заказа.

## Запуск

Нужен Python 3.11.

```bash
python -m venv .venv
```

Активируйте окружение: Windows — `.venv\Scripts\activate`, Linux — `source .venv/bin/activate`.

```bash
pip install -r requirements.txt
```

1. Скопируйте `.env.example` в `.env`, заполните `FUNPAY_TOKEN` и `LZT_TOKEN` с доступом `market`.
2. В `products.json` задайте `seller_ids`, `provider_category_id`, точные поля `expected_fields`, цены и комиссию. После сверки товара и условий активации поставьте `profile_verified=true`. Значения в комплекте — примеры.
3. Добавьте отдельную строку `!nitro nitro-1m` в подробное описание своего лота FunPay. Один заказ — одна ссылка. Nitro, Basic и Trial настраиваются отдельно.
4. Выполните проверку без закупок: `python main.py`.
5. После контрольной проверки установите `ALLOW_PURCHASES=true` и запустите `python main.py --run`.

На Windows также доступны `Check.cmd` и `Start.cmd`.

Команды покупателя: `!заказ`, `!статус`, `!данные`, `!инструкция`, `!возврат`, `!поддержка`, `!помощь`.

Закупки по умолчанию выключены. Реальная закупка и активация пока не проверены. После начала закупки автоматический возврат блокируется; при неизвестном результате бот сверяет прежний товар. Повторная команда выдачи не создаёт новую закупку.

Данные создаются в `data/` и `Base/`. При переносе сохраняйте всю папку `data`, включая ключ шифрования; не запускайте два рабочих экземпляра одновременно.
